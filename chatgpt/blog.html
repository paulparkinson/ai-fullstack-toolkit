Put a FinancialDB table in ChatGPT

A tiny MCP App can make a database table easy to explore: read recent notes, add a note, and keep database access behind the Oracle Database MCP Java Toolkit.

What it does

The app in this directory exposes show-financialdb-notes to ChatGPT. It opens a compact panel that reads the newest notes from CHATGPT_NOTES in the connected database account. A person can add a note after confirming the write in the panel. Both operations call named Oracle Database MCP Java Toolkit tools; the browser never gets a database password or a JDBC connection.

Use either FINANCIAL or ADMIN. The demo creates an isolated table in that account's schema. Keep the Toolkit endpoint private and authenticate remote connections.

Start it locally

  1. Copy .env.example to .env. Set the FinancialDB wallet path, service alias, database password, and Toolkit authentication token. Keep the wallet and .env out of Git.
  2. Set DB_USERNAME to FINANCIAL or ADMIN; set DB_PASSWORD to the corresponding password. Run database/setup.sql once as that account to create its isolated notes table.
  3. Start the Oracle Database MCP Java Toolkit with toolkit-tools.yaml and the chatgpt-notes toolset. Supply database credentials only to that Toolkit process; set its MCP auth token to the same local development token used by ORACLE_MCP_AUTH_TOKEN.
  4. For local-only use, run ./run.sh. For ChatGPT, install OpenAI's tunnel-client, set CONTROL_PLANE_TUNNEL_ID, then enter a runtime CONTROL_PLANE_API_KEY with Tunnels Read and Use through a hidden prompt in the launching shell. Keep the key out of .env, command arguments, and source control. Then run ./run_with_ssl.sh. It builds the app on 127.0.0.1:3001 and forwards MCP requests through a private HTTPS tunnel.
cd chatgpt
cp .env.example .env
# Edit .env and configure the Toolkit process using toolkit-tools.yaml
export CONTROL_PLANE_TUNNEL_ID=tunnel_...
read -s -p "Tunnel runtime key: " CONTROL_PLANE_API_KEY; echo
export CONTROL_PLANE_API_KEY
./run_with_ssl.sh

Connect it to ChatGPT

  1. Run ./run_with_ssl.sh and keep it open. It forwards the loopback-only app through OpenAI Secure MCP Tunnel, so ChatGPT can reach the server without exposing a public listener. Create or select a tunnel associated with the ChatGPT workspace you will use; an Enterprise-only tunnel may not appear in a Personal workspace. The tunnel ID and runtime key come from your OpenAI Platform tunnel setup. This example's runtime key expires after 30 days.
  2. In ChatGPT, open the Plugins page, press +, and choose Add custom MCP server.
  3. Enter a name and description, choose Tunnel under Connection, and select the tunnel used by tunnel-client. Configure authentication as required, review the warning, and create it as a plugin. Workspace policies can restrict custom MCP servers.
  4. Review the discovered tools. Start a new conversation, type @, select the plugin, and ask: Show my FinancialDB notes. The model invokes the read-only dashboard tool and ChatGPT renders its MCP App UI.
  5. Type a note in the app, check the explicit write confirmation, and select Add note. Refresh the list to see the inserted record.

Menu labels and developer-mode availability change by account and product release. Follow the current OpenAI Connect from ChatGPT and MCP Apps compatibility instructions if the menu differs.

Project files

  • toolkit-tools.yaml — narrow read/insert SQL tools for the Oracle Toolkit.
  • server.ts — ChatGPT-facing MCP server and bridge to the Toolkit.
  • src/app.ts — compact MCP App UI.
  • database/setup.sql — isolated demo table setup.

Reusing this sample on another computer does not require starting over. See the new-computer setup guide for local wallet, certificate, Toolkit, and tunnel configuration. Runtime credentials and workspace permissions must be set up for that machine and ChatGPT workspace.
